BEFORE YOU SETTLE IN.

A few things
worth knowing.

Aster is an early desktop preview. Your feedback helps shape what comes next.

Do I need an AI subscription?

You can browse without connecting an AI provider. To use the agent, connect your own OpenAI, Anthropic, or Gemini API account in Settings, or run a local Ollama model. API access and billing are handled by your provider, and provider API charges may apply.

Which Mac download should I choose?

Open the Apple menu and choose About This Mac. If you see “Chip” and an Apple M-series name, choose Apple Silicon. If you see an Intel processor, choose Intel.

What should I expect when installing?

These preview installers are unsigned, and the Mac builds are not notarized. Your operating system may show a security warning. On macOS, you may need to allow Aster in System Settings → Privacy & Security after trying to open it. On Windows, check the downloaded file and its checksum before deciding whether to run an unrecognized app. On Linux, allow the AppImage to run as a program in its file properties.

What can the agent do?

It can summarize selected tabs, compare pages, work through supported browser forms, use saved documents, and draft cover letters using your information. It asks for missing details and follows your selected approval mode. Some sites and controls need manual help, including passwords and CAPTCHAs. Keep an eye on important tasks and review the outcome.

What happens to my data?

Browser and task data are stored in your local Aster profile. Using the agent can send selected page content, relevant document text, and your requests to the provider you configure. Saved documents remain until you remove them, separately from chat history. Your provider's own data policies apply. This website has no analytics or account system. Read the website privacy note.

How can I get support or share feedback?

For setup questions, bug reports, or ideas for Aster, email ayaz@ilhamlabs.io. If something goes wrong, include your operating system, Aster version, and what happened. Keep API keys out of your message.
