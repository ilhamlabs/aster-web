A LITTLE CLARITY.

Privacy, in plain language.

This note covers the Aster download website. The desktop browser and the AI providers you choose have separate data handling.

This website

The site has no analytics, advertising trackers, account system, or application forms. It does not set cookies or store your information in browser storage. Fonts and visual assets are served with the site. JavaScript can read your browser's reported operating system to highlight a suitable download; that information stays in your browser.

Hosting and downloads

The site and installers are hosted through GitHub services. Like other web hosts, GitHub can receive information such as your IP address, browser information, and requested files when you visit or download. Read GitHub's privacy statement for its own practices. This site does not add download tracking.

Inside the desktop app

Aster stores browser data, conversations, and saved documents in your local profile. Provider keys are encrypted using the operating system's credential service. When you use an AI agent, your requests, selected page content, and relevant document text can be sent to the provider you configure. Your provider's data and billing terms apply. A local Ollama setup can be used instead.

Your choices

Agent permissions are selected per task. You can stop a task and manage history, retained memory, saved documents, and provider keys in the app. Saved documents are separate from conversation history and must be removed separately. AI features and task history are disabled in private windows.

An early preview

Aster is still in development. The current installers are unsigned; the macOS versions are not notarized. This website does not claim independent privacy or security certification.
